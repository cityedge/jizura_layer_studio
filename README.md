# JIZURA Layer Studio
**字幕レイヤー制作ツール · cityedge fork · v0.9.0-layer.13**

[アプリを開く](index.html) · [English](README.en.md) · [利用ガイド](docs/LAYER_WORKFLOW.md) · [手動公開の手順](docs/PUBLISHING.md)

他の動画へ重ねる「黒背景の字幕フロント」と「白黒2値マット」を、同じサイズ・fps・フレーム数の2本のMP4として作るブラウザアプリです。

本アプリは、**hakoniwa氏の[JIZURA](https://github.com/852wa/JIZURA)** を基に、cityedgeが字幕レイヤー制作向けに改変した非公式派生版です。原版の作者が本派生版の開発・保守を担当するものではありません。原版の演出エンジンとコミュニティによる翻訳に感謝します。

## はじめに

1. ファイル一式を取得し、`index.html`をPC版Chrome / Edgeで開きます。GitHubのソース表示画面では実行されません。公開者がGitHub Pagesを設定した場合は、そのサイトURLでも使えます。
2. UTF-8のSRTを読み込むか、字幕を直接入力します。
3. 「おまかせ」で演出を作り、必要に応じて各行を調整します。
4. 作業用背景やスペアナ動画を読み込んで見え方を確認します。
5. 「マット＋フロント MP4を出力」で2本を保存します。複数ダウンロードの確認が出たら許可してください。出力後の個別保存リンクも使えます。

アプリ内の「利用ガイド」「利用について」からも説明を確認できます。英語版は`en/index.html`です。原版のその他の言語版も収録していますが、派生版で追加した操作・ガイド・権利表示は日本語／英語対応です。その他の言語では追加部分が英語で表示されます。

## 主な機能

- SRTの開始・終了・改行・空白区間・重複字幕を保持。本文と時刻を編集できます。
- 画像・動画の作業用背景。背景は出力しません。
- 元の文字色・図形・装飾・切替演出を使った字幕制作。
- スペアナ合成。マットは任意、未指定時はRGB 000000だけを透明化します。
- スペアナは画面幅65%、左・下に各3%余白。位置・縦横倍率を調整できます。
- 暗い外周ブルームの除去を0〜128で調整。初期値32。
- 無音のMP4ペアを直接保存。マット名はフロント名に`_matte_dark`を追加。
- 480p・540p・720p・1360×766・900p・1080p・1440p・4K（寸法は画面比で変わります）。
- プロジェクトJSONの保存・復元。

背景・音声入りの完成動画、PNG出力、After Effects出力は、この派生版の提供対象ではありません。

## 外部合成と制限

背景にマットを「比較（暗）」で重ね、その結果にフロントを「比較（明）」で重ねます。2本の位置・サイズ・開始時刻を揃えます。マットをアルファとして使う場合は、白を透明・黒を不透明として扱います。

マットは圧縮前に白黒2値で生成し、半透明アルファは出力しません。非可逆のMP4圧縮後には色や境界が微小に変化することがあります。[詳細仕様](docs/LAYER_WORKFLOW.md)を参照してください。

素材はブラウザ内で処理し、アプリからアップロードしません。フォント取得時にはGoogle Fontsへ接続します。字幕・設定はブラウザに自動保存しますが、明示的なJSON保存も行ってください。背景・スペアナ・曲の実ファイルはJSONに含まず、再度開くときに選び直します。

MP4出力にはWebCodecsとH.264エンコーダーが必要です。PC版Chrome / Edgeを推奨します。ブラウザ・OSにより利用可否が異なります。長時間・4K出力は十分な検証ができていません。まず短い範囲で確認してください。

## 開発・手動配布

Python 3.10以降（標準ライブラリのみ）でビルドします。`python`は使用する環境の実行ファイルに置き換えられます。

```text
python build.py
node dev/layer_test.js
python tools/package_release.py
```

公開用一式は`dist/`に生成します。[手動公開ガイド](docs/PUBLISHING.md)に従い、`upload/`の中身を独立したリポジトリへアップロードしてください。Fork・git push・原版との同期は不要です。

| 場所 | 内容 |
|---|---|
| `index.html`・各言語の`index.html` | ビルド済みアプリ。コードとライセンス表示を内包 |
| `src/` | 描画・演出・字幕・合成・画面のソース |
| `app/` | 画面・CSS・翻訳・利用ガイド・権利表示の編集元 |
| `vendor/` | MP4ライブラリとライセンス |
| `build.py` | 各言語版HTMLの生成 |
| `tools/package_release.py` | 手動アップロード用フォルダの生成 |
| `docs/` | 操作・公開・演出拡張の説明 |
