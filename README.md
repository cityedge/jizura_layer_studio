# JIZURA Layer Studio

**字幕レイヤー制作ツール · cityedge fork · v1.2.1**

SRT読み込み後の「字幕」欄でパート区切りを手動編集できます。Enterで区切りを追加（行頭なら上、それ以外は下）し、空行をBackspace／Deleteで削除します。本文と時刻は保護し、取り消し・JSON保存に対応します。

字幕ガチャに **0：ランダム** を追加。スタイル・雰囲気の枠を外し、適合条件と過密を避ける調整を残して抽選します。2〜5で部分変更でき、Q／6で保持していた基礎設定へ戻せます。

字幕単位ガチャは **1：全体／2：スタイル／3：雰囲気／4：演出／5：配色／6・Q：微調整**。字幕ごとの設定を保って段階的に仕上げられます。マットが不要な場合は「フロントだけ MP4を出力」で生成・エンコードの負荷を減らせます。

[公開アプリを開く](https://cityedge.github.io/jizura_layer_studio/) · [ローカル版](index.html) · [English](README.en.md) · **[詳細ユーザーマニュアル](user_guide.md)** · [短い利用ガイド](docs/LAYER_WORKFLOW.md) · [手動公開の手順](docs/PUBLISHING.md)

他の動画へ重ねる「黒背景の字幕フロント」と「白黒2値マット」を、同じサイズ・fps・フレーム数の2本のMP4として作るブラウザアプリです。

補助機能として、静止画背景・スペアナ・字幕と任意の音源を1本にまとめる[簡易動画出力](user_guide.md#簡易動画を書き出す)も利用できます。

本アプリは、**hakoniwa氏の[JIZURA](https://github.com/852wa/JIZURA)** を基に、cityedgeが字幕レイヤー制作向けに改変した非公式派生版です。原版の作者が本派生版の開発・保守を担当するものではありません。原版の演出エンジンとコミュニティによる翻訳に感謝します。

SRT編集欄の「先頭に字幕を追加」「この後に追加」「削除」で通常字幕を個別に増減でき、Ctrl+Zで戻せます。空欄はスロットを残して描画なし。全角スペースは有効な本文で、半角スペースで区分できます。時刻が不正な間は出力を停止し、修正するとエラーは消えます。

## はじめに

1. ファイル一式を取得し、`index.html`をPC版Chrome / Edgeで開きます。GitHubのソース表示画面では実行されません。公開者がGitHub Pagesを設定した場合は、そのサイトURLでも使えます。
2. UTF-8のSRTを読み込むか、字幕を直接入力します。
3. 「おまかせ」で演出を作り、必要に応じて各行を調整します。
4. 作業用背景を選び、必要なら音源からスペアナを生成するか、外部スペアナ動画を読み込みます。
5. 「マット＋フロント MP4を出力」で2本を保存します。複数ダウンロードの確認が出たら許可してください。出力後の個別保存リンクも使えます。

アプリ内の「利用ガイド」「利用について」からも説明を確認できます。画面は日本語と英語の2言語に対応し、上部の言語メニューで切り替えます。日本語版は`index.html`、英語版は`en/index.html`です。字幕本文の言語・フォント対応とは別の設定です。

## フィラー字幕

SRT読み込み後の「フィラーを追加…」から、前奏・間奏・アウトロの空白に編集可能な仮字幕を生成できます。初期値は全種類オン（空白3・歌詞8・タイムスタンプ2・図形1・指定テキスト0）。指定テキストは任意の本文を設定でき、初期値は空欄です。プリギャップ0.3秒・ポストギャップ0.5秒を引いた残りが5秒以上の区間が対象です。文字の種類・重み・平均長さ・余白をダイアログで調整できます。再生成は手編集したフィラーも置き換え、通常字幕とその演出は保持します。詳しくは[フィラーの説明](docs/LAYER_WORKFLOW.md#フィラー字幕)をご覧ください。

## スペアナ動画を作るツール

内蔵スペアナは曲全体を粗く解析し、250〜4,000Hzを含む周波数範囲を自動設定します。決定値は「自動音域」に表示され、曲の途中では変わりません。FFTサイズ・音量・拍動の処理は維持しています。

アプリ内でも、読み込んだ音源から64本のバーを生成できます。「スペアナの入力」で「音源から生成」を選び、感度・拍動・戻る速さと上下の色を調整します。色は最大高さを基準とする固定グラデーションです。プレビュー・ペア出力・簡易動画出力で同じ動きを使います。詳しくは[内蔵スペアナ](user_guide.md#音源から生成する)をご覧ください。

[Audio Spectrum Overlay Maker](https://github.com/cityedge/audio-spectrum-overlay-maker)は、cityedgeが開発した、本アプリに読み込むスペアナ動画を作るツールです。スペアナ素材を用意するときにご利用ください。

レイヤー制作に関する主な仕様は次のとおりです。

- SRTを編集の出発点として読み込み、本文・開始・終了を編集。タイムラインのクリックで移動、開始ハンドルのドラッグ・数値入力・±0.1秒移動で字幕の時刻を調整できます。開始を動かすと表示時間を維持して終了も移動します。タップ同期はSRT未使用時のみ利用できます。
- 画像・動画の作業用背景。ペア出力には背景を含めません。
- 元の文字色・図形・装飾・切替演出を使った字幕制作。
- スペアナ入力は「なし／音源から生成／外部動画」を切り替えます。外部動画のマットは任意、未指定時はRGB 000000だけを透明化します。
- スペアナは画面幅65%、左・下に各3%余白。位置・縦横倍率を調整できます。
- 後処理で外側へ広がるブルームを常に全除去。文字・図形・スパーク本体と、その内側の明るさの変化は保持します。
- 無音のMP4ペアを直接保存。マット名はフロント名に`_matte_dark`を追加。
- 480p・540p・720p・1360×766・900p・1080p・1440p・4K（寸法は画面比で変わります）。
- 標準30fps。字幕は15／10枚・秒またはフル。スペアナは表示時刻によるフレーム読取。
- プロジェクトJSONの保存・復元。

出力時間は素材の読み込み・変更時に字幕・スペアナ・デコード済み音源の最長へ自動更新し、手動でも修正できます。「音源を含めない」を選んでも音源長は計算対象です。素材の追加・読み替え・解除や字幕時刻の変更があれば再計算します。 背景動画を選択中は簡易出力を利用できません。PNG・After Effects出力は提供していません。

## 外部合成と制限

背景にマットを「比較（暗）」で重ね、その結果にフロントを「比較（明）」で重ねます。2本の位置・サイズ・開始時刻を揃えます。マットをアルファとして使う場合は、白を透明・黒を不透明として扱います。

マットは圧縮前に白黒2値で生成し、半透明アルファは出力しません。非可逆のMP4圧縮後には色や境界が微小に変化することがあります。[詳細仕様](docs/LAYER_WORKFLOW.md)を参照してください。

素材はブラウザ内で処理し、アプリからアップロードしません。フォント取得時にはGoogle Fontsへ接続します。字幕・設定はブラウザに自動保存しますが、明示的なJSON保存も行ってください。背景・スペアナ・曲の実ファイルはJSONに含まず、再度開くときに選び直します。

MP4出力にはWebCodecsとH.264エンコーダーが必要です。PC版Chrome / Edgeを推奨します。ブラウザ・OSにより利用可否が異なります。長時間・4K出力は十分な検証ができていません。まず短い範囲で確認してください。

## 開発・手動配布

Python 3.10以降（標準ライブラリのみ）でビルドします。`python`は使用する環境の実行ファイルに置き換えられます。

```text
python build.py
node dev/layer_test.js
node dev/filler_test.js
node dev/simple_export_test.js
python tools/package_release.py
```

公開用一式は`dist/`に生成します。[手動公開ガイド](docs/PUBLISHING.md)に従い、`upload/`の中身を独立したリポジトリへアップロードしてください。Fork・git push・原版との同期は不要です。

layer.13 / layer.14から更新する場合は、配布フォルダの`DELETE_FROM_REPOSITORY.txt`にある旧ファイルをGitHub上でも削除してください。上書きアップロードだけでは不要になったファイルは消えません。

| 場所 | 内容 |
|---|---|
| `index.html`・各言語の`index.html` | ビルド済みアプリ。コードとライセンス表示を内包 |
| `src/` | 描画・演出・字幕・合成・画面のソース |
| `app/` | 画面・CSS・翻訳・利用ガイド・権利表示の編集元 |
| `vendor/` | MP4ライブラリとライセンス |
| `build.py` | 各言語版HTMLの生成 |
| `tools/package_release.py` | 手動アップロード用フォルダの生成 |
| `docs/` | 操作・公開・演出拡張の説明 |
| `user_guide.md`・`user_guide.en.md` | 残している元JIZURAの機能も含む詳細ユーザーマニュアル |
