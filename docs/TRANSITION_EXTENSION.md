# 前の字幕を残すつなぎ：拡張仕様

対象バージョン：1.3.0

## 目的

前のカットの最終画像を次のカットの冒頭に残し、退場と登場を重ねる。字幕本文を次のレイアウトへ新規に流用せず、SRTの時刻・カット数・レイアウトは変更しない。手動で同じレイアウトを並べなくても、おまかせ・ランダムで選ばれた組み合わせに適用できる。

## 画像と描画の契約

- A：前のカットの終了直前の静止画像。つなぎを再帰適用せず、共通の後処理とHUDを除いて描画する。元の動きを延長再生するものではない。
- B：次のカットの現在時刻の画像。保持・カメラなどは進行する。
- A/Bは字幕・演出用グラフィックのレイヤー。作業用背景、背景動画、スペアナを切断・破片化しない。
- 新しい登録項目だけに `overlap` メタデータを付ける。従来のつなぎの領域置換処理・継続時間・入口置換処理は維持する。
- 新しいつなぎは自分で描画先をクリアし、通常のsource-overで合成する。Aの透明な部分でBを消さない。
- 進行度0はA、1はB。形状の乱数は計画時のシードで固定し、シーク・プレビュー・出力の順序に依存させない。
- 既存のレイヤー処理でフロントを生成し、フロントの非黒画素だけをマットの黒にする。二値マットの仕様は変えない。フェード中はフロントの明るさが変わる。

## 適用条件と自動抽選

- 既存のつなぎの成立条件を前提に、新方式は同一パート内だけで使う。
- SRTの別字幕間では、前の終了と次の開始がミリ秒単位で一致すること。字幕の空き時間やパート区切りをまたがない。フィラーと通常字幕は既存の独立した計画を維持する。
- 次のカットは1秒以上、前のカットは0.45秒以上。短いカットへ新方式を無理に詰め込まない。
- 継続時間は演出ごとの上限、次のカットの65%、次の退場開始までの時間の最小値。字幕の終了を延長しない。
- 前のカットの通常退場はつなぎが担当する。次の通常登場は `incoming: keep` なら併用、`replace` ならつなぎで置換する。
- キネティックの部品として登録。既存のおまかせの雰囲気タグ、候補ON/OFF、重み・繰り返し抑制を使用する。完全ランダムの内部カット間でも適合条件を通して選ぶ。
- 保存済みの従来のつなぎを新方式へ置き換えない。新方式も従来の `trans` / `transP` / `transDur` として保存し、JSON形式の移行を不要とする。

## 追加する3種類

| ID | 日英の表示名 | 上限 | 次の通常登場 | 動作 |
|---|---|---:|---|---|
| `carryRetreat` | 余韻を縮小 / Retreating echo | 1.1秒 | 併用 | Aを少し縮めて上下へ退避し、Bを重ねながら消す |
| `carrySlash` | 斜めに断ち切る / Diagonal split | 0.8秒 | 置換 | Aを斜めの2片に切り、上下へ開いてBを見せる |
| `carryShatter` | 放射状に砕ける / Radial shatter | 0.9秒 | 置換 | Aを11片に分け、外側へ移動・回転しながらBを見せる |

破片数と移動量を固定範囲に制限する。3枚以上の過去画像を積み重ねたり、過去のつなぎを再帰描画したりしない。

## 開発時のつなぎレビュー関数

- 開発用の `J.prepareTransitionReview` を使う。初期検証ではPキーに割り当てていたが、公開版のPは背景レビューに変更済み。現在のO／Pの仕様は [DEBUG_REVIEW.md](DEBUG_REVIEW.md) を参照。
- 現在の字幕にある適用可能な最初のカット境界だけを、今回の3種類から抽選する。直前と同じ種類は選ばない。
- 本文・時刻・レイアウト・配色・全体のおまかせ設定は維持する。前のカットの退場と対象カットの登場は、つなぎに応じて変わる。
- 通常の候補ON/OFFを無視して新方式を試せるが、パート・空き時間・最低長・対象字幕と直前字幕のロックは無視しない。試せない場合は理由を表示し、変更しない。
- 再生中は対象境界の0.3秒前から再生継続。停止中は境界へ移動して停止を維持する。Undo/Redo、JSON保存に対応。
- 変更は通常のカット単位の手動つなぎ指定として保存する。隠れた強制抽選モードをプロジェクト全体へ残さない。「微調整」は手動指定を保持するため、通常の抽選へ戻す場合は対象カットのつなぎを「自動」にするか、演出変更／全体変更を使う。

## 検証

- `node --test dev/transition_test.js`：通常抽選、完全ランダム、部分ガチャ、境界条件、ロック、保存再現、従来方式の時間を検証。
- ブラウザ：開発時のつなぎレビュー操作で、Undo/Redo、再生継続、入力中の抑止、JSONの保存・再読込を検証。公開版のO／Pは塗り面積のレビュー用として別途検証。
- 描画：A/Bの端点一致、透明部分、シーク順序に依存しない再現、フロント／マットの画素対応。
- 出力：ペア・フロントのみ・簡易動画を実際にエンコードし、寸法・FPS・フレーム数を確認する。

全レイアウト・文字列・配色の組み合わせについて見栄えを保証するものではない。輪郭の少ない画面や、レイアウト自身が終端で文字を消す演出では、残せるAの要素が少なくなる。必要に応じてカット単位のつなぎ指定から各演出を選んで確認する。
