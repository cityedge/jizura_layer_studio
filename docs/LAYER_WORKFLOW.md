# 利用ガイド — JIZURA Layer Studio

[English](LAYER_WORKFLOW.en.md) · [README](../README.md)

v1.0.0の短い操作ガイドです。元JIZURAから残している書体・配色・手法・ロックなどを含む説明は、[詳細ユーザーマニュアル](../user_guide.md)をご覧ください。

## 字幕・演出・確認用素材

「SRTを読み込む」でUTF-8のSRTを選びます。開始・終了・改行・空白区間を初期値として読み込み、以後は自由に編集できます。元のSRTファイルは変更しません。重複区間は重ねて描画します。SRT内の `/`、`*`、`|`、`!` は通常の文字です。

タイムラインの帯をクリックすると再生位置が移動します。上部の行開始ハンドルをドラッグするか、行一覧の開始秒を入力して時刻を変更できます。タップによる同期も利用できます。開始を動かすと終了も同じだけ移動し、表示時間を維持します。時刻順が入れ替わっても行ごとの演出設定は字幕について移動します。

「SRTの本文・開始・終了を編集」では本文と時刻を編集できます。終了だけを変更すれば表示時間が変わります。行の編集ボタン・本文のダブルクリックからもこの編集欄を開けます。変更は「元に戻す」／Ctrl+Zで取り消せ、プロジェクトJSONに保存・復元できます。

SRT編集欄の「先頭に字幕を追加」「この後に追加」「削除」で通常字幕を個別に増減でき、Ctrl+Zで戻せます。空欄はスロットを残して描画なし。全角スペースは有効な本文で、半角スペースで区分できます。時刻が不正な間は出力を停止し、修正するとエラーは消えます。

SRTを使わず直接入力する場合は、原版の歌詞記法を使えます。「おまかせ」で演出を作り、行ごとの設定を調整します。「◀」で前の案に戻れます。

演出の板・帯・図形・HUD・フラッシュ等も残るため、画面全体を覆う演出もあります。単なる下地色や独立したタイトル・間奏はレイヤー出力の対象にしていません。

作業用背景に画像・動画を読み込み、「作業用背景＋字幕で表示」で確認できます。背景動画はタイムラインに同期します。「曲とタイミング」の曲は確認・タイミング調整用です。背景も曲も出力しません。

## フィラー字幕

タイムライン上の番号は、通常字幕が灰色、フィラーが赤色です。選択中（ホバー・ドラッグ中）はどちらも黄色になります。初期値の変更は新規設定に適用し、保存済みのフィラー設定は維持します。

SRT読み込み後、「フィラーを追加…」を押すと設定ダイアログが開きます。生成された仮字幕は通常字幕と同じように編集できます。「フィラー」の印は本文を書き換えても残り、再生成では手編集したものも含めてすべて置き換えます。通常字幕の本文・時刻・演出は保持します。「フィラーをすべて削除」も利用でき、生成・削除はCtrl+Zで取り消せます。

- **空白の閾値**：プリギャップ（直前の通常字幕からの余白）とポストギャップ（次の通常字幕までの余白）を差し引いた残りに適用します。初期値は閾値5秒、プリ0.3秒、ポスト0.5秒なので、5.8秒以上の間奏が対象です。前奏にはポストだけ、アウトロにはプリだけを設けます。重なった通常字幕は連続した表示区間として扱います。
- **平均長さ**：現在の通常字幕の表示時間を長い順に並べ、上位50%（端数切り上げ）の平均を「普通」にします。短めは0.75倍、長めは1.5倍です。個々の長さに変化を付け、対象区間を分割します。
- **本文の種類**：空白文字・歌詞テキスト・タイムスタンプ・図形文字をチェックで選び、各1〜10の重みで抽選します。初期状態は全種類オン、重みは順に3・8・2・1です。空白文字は全角スペース2〜5個を半角スペースで3〜4区分に分け、台紙や装飾の演出を利用します。図形文字は通常字幕の平均文字数（空白・改行を除く）に合わせ、同一文字の繰り返し・混在・交互・左右対称などを抽選します。歌詞は通常字幕から長さに関係なく全文を選びます。
- **時刻タグ**：本文の `[timestamp]` を表示時に `02 05 853` の形に置き換えます。開始時刻を動かすと追従します。通常字幕への手入力や他の文字との併用もできます。編集欄とJSONにはタグをそのまま保持します。
- **終端**：音源の長さを優先し、音源がなければスペアナ、どちらもなければ通常字幕の末尾までを対象にします。通常字幕の末尾より短くはしません。アウトロを埋める場合は先に素材を読み込んでください。

フィラーは基準時間・文字数・空白の計算から除外します。設定とフィラーの識別はJSONに保存されます。キャンセルでは変更しません。極端な入力での過剰生成を防ぐため、平均長さは最低0.25秒、図形文字は最大120文字、全字幕は最大20,000件です。

## スペアナ

[Audio Spectrum Overlay Maker](https://github.com/cityedge/audio-spectrum-overlay-maker)は、cityedgeが開発した、本アプリに読み込むスペアナ動画を作るツールです。

フロント動画を読み込むと自動的に合成します。合成のチェックボックスはありません。合成しない場合はフロント動画の「解除」を押してください。字幕が手前、0秒から同期し、素材の終了後は空白です。

対応マットはフロント選択時に2本まとめて選べます。例は `speana_sample.mp4` と `speana_sample_matte_dark.mp4`。同じフォルダにあるだけでは自動で読み込みません。フォルダ選択の操作もありません。

- マットなし：配置・拡縮後にRGB 000000の画素だけ透明です。010101等の近い黒や、圧縮で非ゼロになった黒周辺は残ります。
- マットあり：フロントとサイズ・長さを揃えます。マットのRGB平均128未満を不透明とします。ただしフロントがRGB 000000なら透明です。外部素材で残したい黒は事前に非ゼロにしてください。
- 後からマットを追加・解除できます。ブルームのしきい値はスペアナには適用しません。

基本配置は画面幅65%、元動画の比率を維持し、左・下に画面寸法の各3%余白。横倍率・縦倍率は基本サイズを100%として別々に調整できます。位置と倍率はJSONに保存し、画面外は切り取ります。「基本位置に戻す」で復元できます。プレビューと出力は同じ配置です。

## FPSとスペアナのフレーム

新規プロジェクトの標準は30fpsです。字幕のコマ打ちは15枚／秒（2コマ打ち）、10枚／秒（3コマ打ち）、フル（出力fps）から選べます。「おまかせ」もこの基準を使います。保存済みの24fpsや12／8枚・秒は勝手に変更しません。既存の設定を使っている場合はfpsを30に変更してください。演出部品の秒単位の長さやフェード速度は維持しています。

書き出し時は、スペアナ素材のフレームをWebCodecsでデコードし、表示時刻（PTS）に基づいて選びます。プレビューの動画要素や再生速度からフレームを取得しません。30fps素材を30fpsで、素材のフレーム境界に揃えて出力する場合、素材の各フレームが順番に1回ずつ使われます。「フレームの対応」が一致するという意味で、拡縮・合成・MP4再圧縮後の画素値が素材と完全一致する意味ではありません。

フロントとマットは同じ出力時刻で選びます。2本は事前にタイミングを揃えてください。29.97fps・可変fps・異なるfpsの素材では、表示時刻に応じた間引きや同一フレームの繰り返しが発生します。字幕のコマ打ちはスペアナには適用しません。24fps／60fps出力も選択できます。

対応コンテナはMP4・MOV・WebM・Matroska・Oggです。実際の対応コーデックはブラウザ依存です。素材を正確にデコードできない場合はエラーを表示し、従来のシーク方式へ自動的に戻しません。作業用プレビューは従来の動画要素による再生です。

## 外周ブルームの除去

左ペインの行・演出リスト下で0〜128を指定します。初期値32、0は除去なし、大きいほど暗い外周光彩を多く除去します。プレビューへ即時反映し、再抽選はしません。値はプロジェクトに保存し、出力中は変更できません。

自動ブルームとブルーム画面効果で、描画前に空白だった場所へ追加された光彩だけを判定します。元からある文字・図形・火花は保護します。文字の影やカメラぼけなど、すべての暗い効果を一律に削除するものではありません。

## プレビュー・出力

「作業用背景＋字幕で表示」「黒背景フロント」「白黒マット」を切り替えられます。暗い文字は背景と重ねて確認してください。

「マット＋フロント MP4を出力」で2本を直接保存します。複数ダウンロードの確認が出たら許可してください。保存されなかったファイルは出力後の個別リンクから保存できます。ZIP圧縮はしません。出力中はタブを開いたままにします。

出力名は `プロジェクト名_subtitle_front.mp4` と `プロジェクト名_subtitle_front_matte_dark.mp4`。スペアナ合成時は `subtitle_front` が `combined_front` になります。

| プリセット | 16:9の出力寸法 |
|---|---|
| 480p | 854×480 |
| 540p | 960×540 |
| 720p | 1280×720 |
| 1360×766 | 1360×766 |
| 900p | 1600×900 |
| 1080p | 1920×1080 |
| 1440p | 2560×1440 |
| 4K | 3840×2160 |

画面比に応じて寸法は変わり、縦横とも偶数に丸めます。中間のプリセットは実際の寸法を表示します（9:16では766×1360）。2本は同サイズ・fps・フレーム数で、両方とも無音です。

## 黒とマット

フロントのRGB 000000は空白です。字幕の黒い描画色はRGB 030303にしてからalphaを掛けます。フェード等でRGB 000000に丸まった画素は空白です。

圧縮前の最終フロントで黒以外の場所だけマットを黒、空白を白にします。マットの輪郭を膨らませず、半透明も出力しません。薄い効果は黒地での明るさとして焼き込むため、明るい背景では暗い縁が見える場合があります。

MP4圧縮・色変換後は色や境界に微小な変動があり、完全なRGB値や白黒2値の維持は保証されません。外部合成先でも実際の動画で確認してください。

## 外部合成

1. 背景にマットを「比較（暗）」で合成します。
2. その結果にフロントを「比較（明）」で合成します。
3. 開始位置・表示サイズ・再生速度を揃えます。

独自の処理でマットをalphaに使うなら `alpha = 1 - matte / 255`（白は透明、黒は不透明）です。圧縮前の2値ペアでは `front + background * (matte / 255)` で同じ結果になります。

## 保存・復元と制限

「保存」でJSONを出力し、「開く」で復元します。字幕・演出・配置・ブルーム値を保持しますが、背景・スペアナ・曲の実ファイルは含みません。再度開くときに選び直します。自動保存は補助として使い、重要な作業はJSONで保存してください。言語切り替えでもページを読み直します。

PC版Chrome / Edgeを推奨します。MP4にはWebCodecsとH.264エンコーダーが必要です。ローカルファイル表示の保存領域や対応状況はブラウザによります。出力はメモリ上に構築し、長時間・4Kは十分な検証ができていません。まず短い範囲で確認してください。

背景・音声入り完成動画、PNG、AE出力は提供しません。画面の表示言語は日本語・英語です。字幕本文の言語やフォント対応は維持しています。
