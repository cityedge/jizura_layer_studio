JIZURA Layer Studio user guide

Create animated lyrics and export a finished video with background/audio, or front/matte layers for a video editor.

v@VERSION@ Full user manual (Markdown) covers individual settings, compositing and saved data in detail.

Make your first video

  1. Load lyrics and media

    Import a UTF-8 SRT, audio and a preview background (image/video). You can also type lyrics without SRT. To resume a project, open its JSON and reload only the media. Reimporting SRT replaces restored cues, fillers and local effects.

  2. Create effects

    Choose a theme, including No theme, and use Auto-compose. Seek to a cue and refine it with the subtitle draw buttons or number keys.

  3. Choose an export

    For a finished video, open Simple video settings to set duration, audio and title, then export Simple video MP4. For compositing elsewhere, export Matte + front MP4. Check a short range first.

  4. Save the project too

    Save in the header writes JSON with lyrics, effects and settings. Media file contents are not included.

Change the overall look

Shuffle redraws the arrangement using current settings. Simple mode offers six partial changes: Style, Mood, Palette, Palette fine-tune, Fonts and Arrangement.

Palette shifts the entire color system, including the main color, while retaining light/dark and saturation tendencies. Palette fine-tune is the previous accent/ghost A/B action. Fonts chooses role-based combinations following style and mood. Global color/font actions include locally drawn cues and preserve locked cues, motion, cut structure and timing.

Subtitle draws

  • 0 Random: Explore beyond style/mood preferences, within compatibility and effect-density limits.
  • 1 Everything: Redraw this cue's style, mood, palette, fonts and composition using the selected theme.
  • 2 Style: Change style, fonts and related techniques; keep mood and colors.
  • 3 Mood: Change motion and ornaments; keep style, fonts and colors.
  • 4 Performance: Broadly change layouts, motion and structure; keep style, mood, fonts and colors.
  • 5 Colors: Change only colors, without style/mood constraints.
  • 6 Fine-tune: Draw within the cue's base settings and narrow candidate pool. After 0, return to the retained base settings.
  • 7 Fonts: Change only fonts, without style/mood constraints. Keep mono ornament fonts.
  • 9 Global taste: Clear local choices and redraw using the latest global settings. This does not restore the exact original animation.

Lyrics, times and other cues stay fixed; adjacent joins can change. Keys 2–4 replace manual choices in their scope. Font changes can affect widths and wrapping. Locked cues cannot be drawn. Ctrl+Z undoes changes. After 0, keys 2–5 and 7 can still refine parts.

Ctrl+Z reverses cue edits/draws, library applications and global Palette/Fonts changes in chronological order. Ctrl+Shift+Z / Ctrl+Y redoes them. Proposal history compares looks without reverting lyrics or timing. Media loading, output settings and shared-library management are outside this undo history.

Themes and user themes

System themes are No theme, Lyric video, Kinetic, Japanese, Horror, Pop and Ballad. Selecting alone changes no artwork. Auto-compose enables required expression sets globally; keys 1–3 enable them only inside the cue. Keys 4/6 use applied cue settings, 9 uses the global baseline, and 0/5/7 ignore the selected theme.

Open User themes and choose New. Set 0–10 style and mood weights, Save changes, then select the theme. Zero excludes an entry; each group needs a positive weight. If Choose a random style/mood wins, it chooses uniformly from all eligible candidates in that group, including individually zero-weighted entries.

Hover, focus or tap names for explanations. Choose from mood uses the traditional style lottery for the drawn mood. Reference mood → Use mood distribution fills approximate style weights and sets that mood to 1, all others to 0. Chaos is a mood name, separate from the random entry.

Themes support duplicate, edit and delete, and live in a shared browser library plus project JSON. Export/import theme JSON to move the library; Save changes after importing. Applied definitions remain independent, so deleting a theme or recreating its name does not change existing cue-draw baselines.

Motion library

Open “Motion library…” to the right of Auto-compose. Initially no library item is selected and the motion to save automatically previews. Click “Save motion” to capture the subtitle’s whole composition and generation settings. A name is optional; blank names receive unique sequential names such as motion001. Older data without generation settings cannot supply this initial preview or be saved; regenerate the cue with 1 or 0 first.

Seek to the destination subtitle, reopen, and select an item to preview with the new lyrics. Nothing changes until Apply. Incompatible text lengths/durations show a reason and disable Apply. Locked subtitles cannot be replaced. The “Keep center clear” setting must match the source.

Previews are silent with a checkerboard instead of media backgrounds. With no subtitle selected, or using “Preview sample”, text is generated from the saved lengths and word structure. Save always captures the subtitle selected when opening. Apply seeks to the start, or resumes from 0.3 seconds before it if playback was running when opening. Ctrl+Z undoes it.

Colors, fonts, techniques and cut proportions carry over; layout is recalculated for the new text and frame size. Original lyrics and media are not saved. After Apply, draws 2–4/6 use the inherited framework, 1 uses the selected theme, and 9 uses the destination’s global settings. Draw 6 is not an exact restore.

The shared library supports up to 500 items. Rename/Delete do not change applied subtitles, and Reset project keeps the library. Project JSON includes applied settings only; use “Export/Import library JSON” to transfer the full collection. Equal IDs/content are deduplicated; an equal ID with changed content becomes a separate item (imports up to 20 MB). Export a backup before clearing browser data.

Cues, parts and fillers

Edit SRT text/start/end, add at the beginning or after a cue, or delete cues. The −0.1s/+0.1s buttons shift every cue. Starts clamp to zero; invalid times or nonpositive durations reject the whole change. Empty text draws nothing; ideographic spaces are valid text.

A normal-cue gap of at least 3 seconds starts a part automatically. In the protected subtitle summary, Enter adds a break above the cue at its start, otherwise below. Backspace/Delete on a blank separator joins parts. Manual breaks override automatic detection. Unified look follows parts; cross-cue joins require the same part and matching end/start times.

Add fillers generates placeholders in SRT gaps. Defaults are a 5s threshold, 0.3s pre-gap and 0.5s post-gap: normally a gap of at least 5.8s. Default weights are Whitespace 3, Lyrics 8, Timestamp 2, Symbols 1 and Custom text 0. All-zero weights, or enabled positive-weight Custom text with no text, are errors.

[timestamp] follows the cue's start time. Regeneration replaces edited fillers too, but retains normal cues. Cue edits, parts and fillers support Undo and JSON. Original SRT files remain unchanged. Tap sync is available only without SRT.

Preview and fonts

Space: play/pause. Left/right: 2 seconds. Shift-left/right: cue navigation. A/D: one frame; Shift-A/D: one second. R: global Auto-compose. Ordinary shortcuts do not run in inputs or dialogs.

Preview rates are 1×, 0.8×, 2/3× and 0.5×, with pitch preservation; exports keep their original speed. Use Legacy 1× if audio is unstable. Playback failures also fall back to it. Global draws seek to 0.5s before the first cue. Local draws seek 0.3s before the target when playing, or to its start when paused.

On desktop, scroll the whole center pane. Changing card counts preserves preview size and scroll position. Phone mode scrolls the page.

Detailed font settings and simple-video titles offer an installed-PC-font picker with search and a sample. It requires browser support and permission; enter the family name manually otherwise. Font files and the enumerated list are not saved. Other PCs need the same font installed. Some built-in faces load from Google Fonts.

Spectrum

Generate from audio creates 64 bars and chooses a frequency range around a guaranteed 250–4,000Hz core, capped by the source's available range. The gradient stays fixed to maximum bar height; short bars show only lower colors.

Reset to defaults restores white at both ends, +8dB sensitivity, 100% pulse and 140ms return time, keeping position, scale and frequency range. External video accepts the front and matching _matte_dark.mp4 together. Without a matte, only RGB 000000 is transparent.

Default width is 65% of the frame, with 3% left/bottom margins. Subtitles are in front; spectrum motion is independent of subtitle cadence. Audio Spectrum Overlay Maker can create external spectrum footage.

Opacity and exports

Binary (legacy) / Alpha (grayscale matte) applies to preview and every export. Spectra remain binary. In Alpha mode, Background color opacity ranges from 0–100%, default 40%, and follows background-color references in shapes, text and mixtures. Mixed text colors can remain at 0%; overlaps can increase opacity. Exterior bloom is removed automatically.

Simple video MP4: Composite background, spectrum, subtitles and audio into one file. Simple video settings holds duration, audio exclusion and title. Duration follows the longest material when materials change and remains manually editable. Excluded audio still counts toward duration. Video backgrounds hold their last frame after ending; their own audio is not used.

Show a title throughout or between start/end seconds. Set font, bold/italic, size in 0.5% steps, color, outline, position and translucent black backing. Optional one-second fades shorten for brief intervals. Title text is foremost; backing sits above the background and below subtitles/spectrum. Titles appear only in composite preview and simple exports.

Matte + front: Save two silent MP4s with subtitles and spectrum, excluding background media, audio and title. Allow multiple downloads or use the individual save links after export.

Binary: background → matte with Darken → front with Lighten. Alpha: background → grayscale matte with Multiply → matching front with Add. Align their starts and sizes. Matte white means transparent, black opaque. Alpha front RGB is premultiplied: do not multiply it by alpha again.

When Add is unavailable but Difference is available: From back to front use ① background (Normal), ② grayscale matte (Multiply), ③ full white layer (Difference), ④ alpha front (Difference), ⑤ full white layer (Difference). All layers use 100% opacity and matching size/range. This equals Add when each RGB component of background × matte + front is at most 1. Exclusion is a different operation.

Front only: Export one silent black-background video, skipping matte generation. Matching a separately exported matte is not guaranteed; alpha compositing requires a matching pair. Empty binary front pixels are black and black artwork uses RGB 030303 before compression; MP4 introduces some error.

Desktop Chrome/Edge is recommended for MP4. WebCodecs and H.264 are required; audio in simple exports needs AAC support. Keep the tab open during export. Long, high-resolution exports use more memory.

Save, resume and reset the project

Current lyrics/settings autosave in the browser, but use Save to create a JSON backup. JSON restores edited cues and fillers; reload audio, background and external spectra separately. Audio and font binaries are not stored in the browser.

Reset project clears current lyrics, fillers, parts, effects, locks, loaded media, spectrum/opacity/export/title settings, playhead and histories. Temporary export links are removed and autosave becomes the blank project. This cannot be undone after confirmation.

Shared libraries are kept. User themes and other cross-project data, interface language, display mode and preview volume remain. Original media, saved JSON and exported files on your PC are not deleted. Delete shared items in their own management screens.
