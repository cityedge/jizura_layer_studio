JIZURA Layer Studio User Guide

v@VERSION@ Detailed user manual (Markdown): Auto-compose, fonts, effects, techniques, line/cut editing, fillers, compositing and saving. The instructions below are a quick workflow.

Create an animated subtitle front with a binary/grayscale matte, or a finished MP4 with background and audio.

  1. Import subtitles

    Choose a UTF-8 SRT with “Import SRT”. Start/end times, line breaks and gaps are preserved. Use “Edit SRT text, start and end” to make changes. You can also type subtitles without an SRT.

  2. Create effects and preview

    Use Auto-compose, then adjust individual lines. Load an image or video as a preview background to check the composite. Front/matte pair exports exclude the background and audio.

  3. Add a spectrum if needed

    Choose Generate from audio or External video under Spectrum source. Audio generation provides 64 bars with sensitivity, pulse strength, return time and top/bottom color controls. The gradient stays fixed to the maximum height, so short bars show only the lower colors. After analysis, preview and export share the same motion.

    For external footage, select the front and matching “name_matte_dark.mp4” together if available. Without a matte, only RGB 000000 is transparent. Select None to hide the spectrum. Default placement is 65% of frame width, with 3% left/bottom margins and adjustable scales. Subtitles appear in front; both start at time zero.

  4. Exterior bloom is removed automatically

    All exterior bloom added by post-processing is removed, regardless of brightness. Text, graphics, sparks and interior brightness changes remain. There is no adjustment control; thresholds in older projects are ignored.

  5. Save two MP4 files

    Select aspect ratio, resolution and fps, then “Export matte + front MP4”. Allow multiple downloads if the browser asks. Individual save links remain available if either file is missing. Both videos are silent and are downloaded without ZIP compression. Keep the tab open during export.

  6. Composite in your video editor

    For Binary mode, apply the matte to the background with Darken, then apply the front with Lighten. For Alpha mode, use Multiply then Add. Keep both videos aligned in time and size. If using the matte as alpha, invert it so white is transparent and black is opaque.

Preview Speed offers 1×, 0.8×, 2/3× and 0.5× with pitch-preserving audio and synchronized subtitles, background video and spectrum. It does not affect MP4 exports or cue times and is not saved in JSON. Pitch correction may slightly change the sound's texture. Tap sync uses 1×.

Mouse adjustments to main-editor dropdowns, checkboxes and sliders return focus for number-key shortcuts. Text/number editing, dialogs and keyboard-operated settings keep focus. Clicking the preview image or timeline also returns from an input field.

If audio behaves poorly, select Legacy 1× at the bottom of Speed to use the original Web Audio player. Standard loading/playback failures or a 10-second startup wait also switch automatically at the current position, with a message. Legacy playback is always normal speed; if it also fails, playback stops. Choose a regular speed to switch back. MP4 exports are unaffected.

The built-in spectrum scans the whole song and selects a range including 250–4,000 Hz, limited by the source Nyquist frequency. Auto range shows the result, fixed for the song, or a default-range note if estimation fails. FFT sizes and pulse processing are unchanged; color, placement and sensitivity changes do not change the range.

Optional simple video MP4

Export simple video MP4, below the pair-export description, saves one flattened video: image/video background, then spectrum, then subtitles. No background means black. Background videos start at timeline zero and hold their final frame after ending. Only the separately loaded song is included; background audio is ignored. Both generated and external spectra can be used.

Duration automatically follows the longest subtitle, spectrum, decoded audio or video background when materials are loaded or changed, and remains manually editable. Background duration uses the video track's end time. Audio counts even with Exclude audio checked. Ended audio becomes silent and ended overlays disappear. Range exports keep all sources at their original timestamps. Video backgrounds require a supported decoder; unsupported media reports a reason.

Existing resolution, fps, quality and export-range settings apply. A selected range trims the output; actual video duration appears below the button. Audio output requires AAC encoding support. Preview volume does not affect export; the source audio retains its original level.

Use Add subtitle at start, Add after and Delete in the SRT editor to add/remove normal cues; Ctrl+Z undoes changes. Empty text keeps a silent slot. Ideographic spaces are valid text; ASCII spaces separate groups. Invalid times block export until corrected.

Whitespace fillers use 3–4 groups of 2–5 ideographic spaces, separated by ASCII spaces. Text is invisible; plates and decorations depend on the chosen effect.

SRT is an editable starting point

The -0.1s and +0.1s buttons beside Add subtitle at start move all starts and ends, including fillers. Starts clamp at zero; moving only the end earlier shortens that cue. Missing/invalid times or a resulting zero/negative duration abort the whole operation without changes. Ctrl+Z undoes it. The source SRT and audio beat grid are unchanged.

Imported cues remain editable. Click the timeline band to seek. Drag an upper start handle or type a row start time to move both start and end while preserving duration. Use “Edit SRT text, start and end” to change text or just the end. Undo / Ctrl+Z restores edits; save them in project JSON. The source SRT file is never modified. Tap sync is available only without SRT. Importing SRT during tap sync ends the session and pauses playback.

Add fillers to subtitle gaps

After importing SRT, “Add fillers…” opens a settings dialog. The threshold applies after subtracting pre/post gaps. Defaults are 5s, 0.3s pre-gap and 0.5s post-gap, requiring an interior gap of at least 5.8s. Intros use only post-gap; outros only pre-gap. The end is based on audio, then spectrum, otherwise the last normal cue.

Normal duration is the mean of the longer half of normal cue durations, rounding the count up; Short uses ×0.75 and Long ×1.5. Individual durations vary. Symbols follow mean normal text length with repeated or mixed patterns; lyrics are selected whole regardless of length. Enable each type and choose weights from 0–10. Defaults enable all types, with weights Whitespace 3, Lyrics 8, Timestamp 2, Symbols 1, Custom text 0.

Custom text uses the full text you enter and starts empty. If enabled with a positive weight but no text, generation shows an error and keeps existing fillers. Weight 0 excludes it from selection.

[timestamp] displays the cue start time (for example 02 05 853) and follows retiming. It can also be typed into normal cues. Fillers are editable placeholders and retain their identity after text edits. Regeneration replaces every filler, including edited ones, preserving normal cues and effects. Remove all, Ctrl+Z and JSON persistence are supported.

Create spectrum videos

Audio Spectrum Overlay Maker is a tool developed by cityedge for creating spectrum videos to import into this app. Use it to prepare your spectrum footage.

FPS and spectrum

Under Generate from audio, Reset to defaults restores white top/bottom colors, +8dB sensitivity, 100% pulse strength and 140ms return time. Placement, scale and the automatic frequency range stay unchanged.

The default is 30fps. Subtitle cadence offers 15 drawings/s (on twos), 10 drawings/s (on threes), and full output fps. Saved 24fps and legacy cadences are preserved. Spectrum export selects decoded frames by presentation timestamp, independently of subtitle cadence. A constant 30fps source exported at 30fps from a source frame boundary uses each source frame once in order. 29.97fps, variable or mismatched frame rates require holds or drops. Unsupported sources report an error.

Parts and subtitle rerolls

Global Auto-compose, partial changes, Shuffle and look history seek to 0.5 seconds before the first nonempty cue, clamped to zero. Fillers and whitespace effects count. Simple/Phone modes start playback automatically; Advanced mode preserves the playing/paused state.

By default, a gap of at least 3 seconds between normal subtitles starts a new part; fillers do not define automatic boundaries. In the subtitle summary, Enter / Add part break inserts a separator above the current cue at its start, otherwise below; Backspace/Delete / Remove part break on a blank separator joins parts. Text is protected; ↵ marks embedded text line breaks. Manual choices override automatic detection and support Undo and JSON. Each choice belongs to the following cue and disappears if that cue is deleted or regenerated as a filler. Unified look follows parts. Cross-cue joins are eligible only within a part when the previous end equals the next start.

Subtitle draws: 0 Random, 1 Everything, 2 Style, 3 Mood, 4 Performance, 5 Colors, 6 Fine-tune, 9 Global taste. Random explores compatible combinations without style/mood preferences, with limits on effect density. Use 2–5 to modify parts of a random composition, or 6 to redraw within its retained base settings. Colors changes only the palette, preserving motion and cut structure.

9 clears the cue's local taste, manual techniques and forced cut counts, then redraws using the latest global style, mood, palette, fonts, candidates and Unified look. It does not restore the exact original animation. Global changes update the baseline; subtitle draws do not. The baseline is saved in JSON; older projects use their existing global settings.

Text, cue times and other subtitles stay fixed except for adjacent joins. Modes 2–4 replace manual choices within their scope; ordinary Fine-tune retains them. Random bypasses Unified look while respecting effect-pack permissions. Locked cues are skipped. Playing previews restart 0.3 seconds before the cue; paused previews stay at its start. Ctrl-Z and project JSON preserve local results.

Space: play/pause. Left/right: 2 seconds. Shift-left/right: cue navigation (left returns to the current start, or the previous cue when near the start). A/D: one frame. Shift-A/D: one second. R: whole-project Auto-compose. These normal shortcuts do not run in inputs or dialogs.

Themes for Auto-compose and subtitle draws

Choose No theme, Lyric video, Kinetic, Japanese, Horror, Pop or Ballad beside Auto-compose or in Simple mode. Selecting alone changes no effects. Whole-project Auto-compose enables required sets globally; cue draws 1–3 enable them only inside the target cue. Key 2 preserves mood/palette; 3 preserves style/fonts/palette. Use 1 for a complete themed change.

Keys 4/6 use the cue's applied settings; 9 uses the last globally applied settings and theme. Selecting another theme does not change the baseline for 9. Keys 0/5 are not constrained by the selected theme. Settings persist in JSON; older projects use No theme.

Hide decorative numbers and times

The checkbox under Subtitle layers hides numeric ornaments such as No.01 and timecodes. Subtitle numbers and [timestamp] remain. Frames and nonnumeric ornaments such as REC are unaffected. Default: off. Applies to preview and all exports, is saved in JSON, and does not reroll effects.

Save and restore

Save a project JSON with the top Save button. It preserves subtitles, effects and spectrum placement, but not the actual background, spectrum or song files. Reload those media files when reopening. Audio/font binaries are not stored by the app; install additional fonts on the PC and enter their family names. Opening JSON displays a reminder. Subtitles and fillers are restored, so do not reimport SRT. Save your project before switching languages.

Opacity modes

Binary (legacy) / Alpha (grayscale matte) applies to preview and all exports. Older JSON projects remain binary. Spectra stay binary; translucent subtitles blend over them. Simple video retains opacity when compositing onto the background.

Alpha pairs use _alpha filenames and premultiplied RGB. The matte is white for transparent, black for opaque. Multiply the background by the matte, then add the front: result = front + background*(matte/255). Do not apply alpha to the front again. Darken/Lighten applies only to binary mode. The front alone cannot reproduce opacity.

When Add is unavailable but Difference is available

Stack from back to front: 1. Background (Normal); 2. Grayscale matte (Multiply); 3. Full-frame white (Difference); 4. Matching Alpha-mode front (Difference); 5. Full-frame white (Difference). Keep every layer at 100% opacity and both white layers at the same full-frame size and time interval.

This equals Add when background × matte + front is at most 1 in every RGB channel, as for a correct ordinary premultiplied pair. Check a short range for color-processing/compression differences. Exclusion is a different operation. See Compositing in a video editor in the detailed manual for the formula and full procedure.

Output characteristics

Export front MP4 only saves one silent video on black, including any spectrum but excluding audio and the preview background. It skips matte pixel generation and encoding. Matching a matte exported separately later is not guaranteed; use pair export when you need a matching matte.

In Alpha mode, adjust Background color opacity from 0–100% (default: 40%). Higher values make fills more opaque, including color mixtures. The setting applies to previews and all exports and is saved in project JSON. Text, foreground parts, transitions and post effects using that color also inherit its opacity. Other palette fields, fixed colors and spectrum opacity are unaffected. At 0%, mixed text/accent contributions remain; at 100%, effect fades still apply. Overlapping fills increase opacity. Saved palettes, random choices and Binary mode remain unchanged.

Pure black in the front means empty space. Black subtitle artwork is processed as RGB 030303. In Binary mode, before compression, exactly the nonblack pixels in the final front have a black matte. Binary mode has no partial transparency. MP4 compression can slightly change colours and edges.

Desktop Chrome / Edge is recommended. MP4 export requires WebCodecs and H.264 encoding support. Long or high-resolution exports use more memory; start with a short range.
