JIZURA Layer Studio User Guide

v@VERSION@ Detailed user manual (Markdown): Auto-compose, fonts, effects, techniques, line/cut editing, fillers, compositing and saving. The instructions below are a quick workflow.

Create an animated subtitle front and binary matte to composite over another video.

  1. Import subtitles

    Choose a UTF-8 SRT with “Import SRT”. Start/end times, line breaks and gaps are preserved. Use “Edit SRT text, start and end” to make changes. You can also type subtitles without an SRT.

  2. Create effects and preview

    Use Auto-compose, then adjust individual lines. Load an image or video as a preview background to check the composite. Front/matte pair exports exclude the background and audio.

  3. Add a spectrum if needed

    Choose Generate from audio or External video under Spectrum source. Audio generation provides 64 bars with sensitivity, pulse strength, return time and top/bottom color controls. The gradient stays fixed to the maximum height, so short bars show only the lower colors. After analysis, preview and export share the same motion.

    For external footage, select the front and matching “name_matte_dark.mp4” together if available. Without a matte, only RGB 000000 is transparent. Select None to hide the spectrum. Default placement is 65% of frame width, with 3% left/bottom margins and adjustable scales. Subtitles appear in front; both start at time zero.

  4. Exterior bloom is removed automatically

    All exterior bloom added by post-processing is removed, regardless of brightness. Text, graphics, sparks and interior brightness changes remain. There is no adjustment control; thresholds in older projects are ignored.

  5. Save two MP4 files

    Select aspect ratio, resolution and fps, then “Export matte + front MP4”. Allow multiple downloads if the browser asks. Individual save links remain available if either file is missing. Both videos are silent and are downloaded without ZIP compression. Keep the tab open during export.

  6. Composite in your video editor

    Apply the matte to the background with Darken, then apply the front with Lighten. Keep both videos aligned in time and size. If using the matte as alpha, invert it so white is transparent and black is opaque.

The built-in spectrum scans the whole song and selects a range including 250–4,000 Hz, limited by the source Nyquist frequency. Auto range shows the result, fixed for the song, or a default-range note if estimation fails. FFT sizes and pulse processing are unchanged; color, placement and sensitivity changes do not change the range.

Optional simple video MP4

Export simple video MP4, below the pair-export description, saves one flattened video: still background, then spectrum, then subtitles. No background means black. A selected video background disables this option; replace it with a still or clear it.

Duration automatically follows the longest subtitle, spectrum or decoded audio when materials are loaded or changed, and remains manually editable. Audio counts even with Exclude audio checked. Loading, replacing or clearing media and changing subtitle times recalculate it. Ended audio becomes silent, ended overlays disappear, and the still remains until the specified end.

Existing resolution, fps, quality and export-range settings apply. A selected range trims the output; actual video duration appears below the button. Audio output requires AAC encoding support. Preview volume does not affect export; the source audio retains its original level.

Use Add subtitle at start, Add after and Delete in the SRT editor to add/remove normal cues; Ctrl+Z undoes changes. Empty text keeps a silent slot. Ideographic spaces are valid text; ASCII spaces separate groups. Invalid times block export until corrected.

Whitespace fillers use 3–4 groups of 2–5 ideographic spaces, separated by ASCII spaces. Text is invisible; plates and decorations depend on the chosen effect.

SRT is an editable starting point

The -0.1s and +0.1s buttons beside Add subtitle at start move all starts and ends, including fillers. Starts clamp at zero; moving only the end earlier shortens that cue. Missing/invalid times or a resulting zero/negative duration abort the whole operation without changes. Ctrl+Z undoes it. The source SRT and audio beat grid are unchanged.

Imported cues remain editable. Click the timeline band to seek. Drag an upper start handle, type a row start time, or use tap sync to move both start and end while preserving duration. Use “Edit SRT text, start and end” to change text or just the end. Undo / Ctrl+Z restores edits; save them in project JSON. The source SRT file is never modified.

Add fillers to subtitle gaps

After importing SRT, “Add fillers…” opens a settings dialog. The threshold applies after subtracting pre/post gaps. Defaults are 5s, 0.3s pre-gap and 0.5s post-gap, requiring an interior gap of at least 5.8s. Intros use only post-gap; outros only pre-gap. The end is based on audio, then spectrum, otherwise the last normal cue.

Normal duration is the mean of the longer half of normal cue durations, rounding the count up; Short uses ×0.75 and Long ×1.5. Individual durations vary. Symbols follow mean normal text length with repeated or mixed patterns; lyrics are selected whole regardless of length. Enable each type and choose weights from 0–10. Defaults enable all types, with weights Whitespace 3, Lyrics 8, Timestamp 2, Symbols 1, Custom text 0.

Custom text uses the full text you enter and starts empty. If enabled with a positive weight but no text, generation shows an error and keeps existing fillers. Weight 0 excludes it from selection.

[timestamp] displays the cue start time (for example 02 05 853) and follows retiming. It can also be typed into normal cues. Fillers are editable placeholders and retain their identity after text edits. Regeneration replaces every filler, including edited ones, preserving normal cues and effects. Remove all, Ctrl+Z and JSON persistence are supported.

Create spectrum videos

Audio Spectrum Overlay Maker is a tool developed by cityedge for creating spectrum videos to import into this app. Use it to prepare your spectrum footage.

FPS and spectrum

The default is 30fps. Subtitle cadence offers 15 drawings/s (on twos), 10 drawings/s (on threes), and full output fps. Saved 24fps and legacy cadences are preserved. Spectrum export selects decoded frames by presentation timestamp, independently of subtitle cadence. A constant 30fps source exported at 30fps from a source frame boundary uses each source frame once in order. 29.97fps, variable or mismatched frame rates require holds or drops. Unsupported sources report an error.

Save and restore

Save a project JSON with the top Save button. It preserves subtitles, effects and spectrum placement, but not the actual background, spectrum or song files. Reselect those files when reopening. Save your project before switching languages.

Output characteristics

Pure black in the front means empty space. Black subtitle artwork is processed as RGB 030303. Before compression, exactly the nonblack pixels in the final front have a black matte. The matte is binary, without partial transparency. MP4 compression can slightly change colours and edges.

Desktop Chrome / Edge is recommended. MP4 export requires WebCodecs and H.264 encoding support. Long or high-resolution exports use more memory; start with a short range.
